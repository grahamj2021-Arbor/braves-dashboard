# Braves Dashboard

A modern baseball analytics dashboard built with **Next.js 16.2.6** and **React 19**.

## Stack

- **Framework:** Next.js 16.2.6
- **Runtime:** React 19.2.4
- **Styling:** Tailwind CSS 4 + shadcn/ui
- **Data Fetching:** TanStack React Query 5
- **Charts:** Recharts 3
- **Icons:** Lucide React
- **Date Handling:** date-fns
- **Build Tool:** TypeScript 5

## Getting Started

### Development

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser. The app auto-refreshes as you edit files.

### Build

```bash
npm run build
npm start
```

### Linting

```bash
npm run lint
```

## Project Structure

- `app/` - Next.js App Router pages and layouts
- `components/` - Reusable React components
- `lib/` - Utility functions and helpers
- `public/` - Static assets
